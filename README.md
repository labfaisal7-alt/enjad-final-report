# لوحة التقرير النهائي

تصميم عربي RTL للوحة التقرير النهائي لجمعية إنجاد، مع فصل البيانات عن الواجهة.

## تعديل البيانات

عدّل ملف `data.js` فقط:

- بيانات الجهة والعنوان في `organization`
- البطاقات العلوية في `kpis`
- الرسوم والقوائم في `daily`, `cases`, `locations`, `members`, `forms`

## التشغيل المحلي

افتح `index.html` مباشرة، أو شغّل خادم معاينة محلي:

```bash
node server.mjs
```

ثم افتح:

```text
http://127.0.0.1:4173/
```

## روابط الصفحات بعد النشر

- `/` لوحة البيانات
- `/report` التقرير الجاهز للطباعة PDF
